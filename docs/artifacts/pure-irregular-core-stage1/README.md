# Pure Irregular Core Stage 1 Evidence

This directory is the portable copy of the strict production matrix generated
from source commit `06c7280240a142b7fbbf302e4f1b7efa013e7310`.

- `summary.json` records nine passing fixture/sheet cases and 18 passing
  Compact/Short Side layouts.
- `manifest.json` binds the source commit, exact command template, Node/V8
  runtime, sequential single-process execution, renderer, and artifact hashes.
- `SHA256SUMS` verifies the generated evidence set.
- Each layout has its JSON report, SVG, and Chromium-rendered PNG.

The added README is explanatory metadata and was not part of the immutable
generated manifest. The experiment interpretation is in
[`../../research/pure-irregular-core-stage1.md`](../../research/pure-irregular-core-stage1.md).
